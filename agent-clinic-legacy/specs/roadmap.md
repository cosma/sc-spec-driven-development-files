# AgentClinic Roadmap

## Goal: Launch MVP with Core Features (6 months)

Ordered by implementation priority and stakeholder value. Each phase is 1–2 weeks of focused work.

---

## Phase 1: Feedback Foundation
**Goal:** Establish user voice mechanism
**Stakeholder:** Susan (product) — capture feature requests early
**Tasks:**
- Feedback form UI (React component)
- Submission storage (PostgreSQL)
- Admin view for review
**Acceptance:** Form deployed, submissions flowing

---

## Phase 2: Social Proof
**Goal:** Build trust with user reviews
**Stakeholder:** Steve (marketing) — attractive site needs testimonials
**Tasks:**
- Customer review collection UI
- Review moderation workflow
- Display on site (homepage/about)
**Acceptance:** 3+ reviews live, visible on public pages

---

## Phase 3: About & Location
**Goal:** Establish clinic identity and accessibility
**Stakeholder:** Steve (marketing) — professional presence
**Tasks:**
- About page (mission, team, values)
- Contact address/map integration
- Staff/agents directory
**Acceptance:** About page indexed, map functional

---

## Phase 4: Dashboard MVP
**Goal:** Core agent & ailment management
**Stakeholder:** Mary (engineering) + Susan (product)
**Tasks:**
- Agent profile creation/editing
- Ailment logging and categorization
- Therapy/treatment assignment
- Basic dashboard layout
**Acceptance:** Users can create agents, log ailments, assign therapies

---

## Phase 5: Appointment Booking
**Goal:** Functional therapy scheduling
**Stakeholder:** Susan (product) — core feature
**Tasks:**
- Booking calendar UI
- Availability management
- Confirmation/reminder system
**Acceptance:** Book appointment → confirmation email sent

---

## Phase 6: Hardening & Launch
**Goal:** Production readiness
**Stakeholder:** Mary (engineering)
**Tasks:**
- Performance optimization
- Security audit (auth, data validation)
- Load testing
- Documentation
**Acceptance:** All features stable, zero known critical bugs

---

## Future (Post-MVP)
- Advanced analytics (agent health trends)
- Integration with external testing tools
- Community features (therapy library, case studies)
- Mobile app
